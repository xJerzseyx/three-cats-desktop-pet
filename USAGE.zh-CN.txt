伊二三万 1.3

新版变化

三只猫可独立拖出并重新排队，离队猫与队伍共用音乐节拍。
归队时显示队尾预览，松手确认的站位和位置会在重启后恢复。
逗猫棒、猫条、猫薄荷三套主题的文字输入光标均已细化。

开始使用

更新时先从旧版托盘菜单选择“退出程序”，再打开新版 EXE。
将压缩包解压到可写文件夹，双击“伊二三万.exe”。
适用 Windows 10 / Windows 11 的 64 位系统，使用 Windows 自带的 .NET Framework 4.x。
猫咪图片和光标已内嵌在 EXE 中，运行时只需要这个 EXE。
100% 对应 600 像素宽度，默认 50% 对应 300 像素宽度。
已有配置文件时，继续使用保存的大小。
重复打开 EXE 会显示已经运行的桌宠。

操作方式

左键按住单猫拖动，可以将它独立摆放，其余队伍成员会自动靠拢。
按住 Shift 拖动队伍中的猫，可以移动当前队伍。
拖动离队猫回到队伍附近时，会显示队尾插入预览，松手后追加到最右侧。
三只猫全部离队后，拖动时仍会在原队伍位置显示淡色归队标记。
按 Esc 或失去鼠标捕获会取消本次拖动，恢复先前确认的站位。
鼠标停在猫身上滚动滚轮，可以调整整组大小。
右键猫咪或右键系统托盘中的猫头像，可以打开菜单。
菜单提供大小档位、音乐来源设置、开机自启动、移回主屏幕、显示或隐藏、退出程序。
单击托盘图标也可以切换显示和隐藏。
隐藏时暂停动画和音频检测，保留托盘入口。
托盘图标也可能位于 Windows 的隐藏图标区域中。

全局光标

首次启动自动启用逗猫棒。右键托盘图标，打开“全局光标”即可切换皮肤。
选择“关闭并恢复原光标”可恢复 Windows 当前保存的方案，下次启动仍保持关闭。
退出程序会恢复原方案。下次启动时会重新启用上次选择的皮肤。

开机自启动

右键托盘图标，勾选“开机自启动”，即可在当前用户登录 Windows 时启动桌宠。
再次点击并取消勾选，即可关闭自启动。
此选项通过当前用户注册表的 Run 启动项保存，启动项名为 ThreeCatsDesktopPet。
仅在手动切换该选项时写入启动项。
更新为“伊二三万.exe”或移动程序后，先取消勾选，再重新勾选，可以更新启动路径。
准备移除程序时，先取消“开机自启动”。

音乐来源

默认选择 cloudmusic.exe 和 qqmusic.exe，对应网易云音乐和 QQ 音乐。
使用本地播放器时，打开“音乐来源设置”，点击“选择播放器 EXE…”并保存。
也可以先让播放器播放音乐，再点击“刷新音频程序”，勾选对应程序并点击“添加勾选程序”，最后保存。
进程名支持每行一个、逗号或分号分隔，大小写和 .exe 后缀均可省略。
可以粘贴从资源管理器复制的带引号 EXE 路径。
播放器若使用独立音频进程，请在音频程序列表中选中实际发声的进程。

三只猫同步随选定播放器的声音强弱变化点头摇摆。
音乐动作启用时暂停头部跟随，连续安静约半秒后恢复。
短暂静音会保留音乐模式，减少模式频繁切换。
头部采用二维转动和位移，瞳孔在眼睛内部跟随鼠标偏移。
按播放器来源筛选，播放器内部的广告和语音同样会触发动作。
其他程序即使同时播放声音，也会被排除。

设置保存

每只猫的位置、队伍顺序、队伍基准、大小和播放器名单保存在 EXE 同目录的“三猫桌宠设置.xml”中。
拖动松手后保存确认状态，重启会恢复。旧版位置和大小可自动迁移。
将程序放在可写文件夹中即可记住设置。
自启动状态由当前用户的 Windows 启动项保存。
移动到其他电脑后，若旧位置超出当前屏幕，启动时会自动移回可见区域。
也可以使用托盘菜单“移回主屏幕”。

验证范围

已在 Windows 10 22H2 64 位系统、内部版本 19045 上完成构建和运行验证。
28 项逻辑测试、6 项自启动临时注册表测试、54 项集成检查通过，单猫渲染与光标加载、回滚检查通过。
已验证单猫拖出、Shift 移动队伍、空队伍归位、队尾预览、确认状态与空队伍的重启恢复。
已验证首次启动 50% 大小、瞳孔在音乐期间跟随鼠标、头部在音乐期间保持音乐动作。
自启动读写在独立临时测试键中验证，实际 Windows 注销重登启动尚未测试。
已用独立音频程序同时播放的方式验证音源筛选、选定来源停止及忽略其他音源。
网易云音乐、QQ 音乐具体客户端，以及 Windows 11，尚未逐一实机验证。
置顶遵循 Windows 窗口层级，独占全屏和系统安全桌面的显示由 Windows 控制。
